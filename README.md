DFI — библиотека для программного формирования интерфейса управляемых форм 1С.
Вместо десятка строк на каждый элемент формы вы пишете один вызов: библиотека сама создает элемент, задает ему вид, путь к данным, свойства и обработчики событий.

## Установка
1. Создайте в конфигурации общий модуль, например `ДФИ`, с флажком «Сервер».
2. Скопируйте в него содержимое файла `ModuleDFI.bsl`.

Вызывать функции библиотеки нужно на сервере, обычно из обработчика `ПриСозданииНаСервере` формы. В примерах ниже модуль называется `ДФИ`.

## Быстрый старт
Пример добавляет на форму два реквизита, группу с полями и кнопку с командой:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

	// Реквизиты формы
	Реквизиты = Новый Структура;
	Реквизиты.Вставить("Комментарий", ДФИ.ОписаниеТипаСтрока(100));
	Реквизиты.Вставить("Срочно", ДФИ.ОписаниеТипаБулево());
	ДФИ.СоздатьРеквизиты(ЭтотОбъект, Реквизиты);

	// Группа и поля в ней
	ДФИ.СздГруппаОбычная(ЭтотОбъект, "ГруппаДополнительно", Неопределено, "Дополнительно", 1);
	ДФИ.СздПоле(ЭтотОбъект, "ПолеКомментарий", "ГруппаДополнительно", "Комментарий", 1, "Комментарий");
	ДФИ.СздПолеФлажок(ЭтотОбъект, "ПолеСрочно", "ГруппаДополнительно", "Срочно", 2, "Срочно");

	// Команда и кнопка
	ДФИ.СоздатьКоманду(ЭтотОбъект, "Проверить", "Проверить", "ПроверитьЗаполнение");
	ДФИ.СздКнопка(ЭтотОбъект, "КнопкаПроверить", "ГруппаДополнительно", "Проверить", "Проверить", 1);

КонецПроцедуры

&НаКлиенте
Процедура ПроверитьЗаполнение(Команда)
	// Действие команды
КонецПроцедуры
```

## Общие правила вызова
Функции создания элементов начинаются с префикса `Сзд` и возвращают созданный элемент формы. У большинства из них одинаковые параметры:

| Параметр | Назначение |
|---|---|
| `Форма` | Форма, на которой создается элемент. Обычно `ЭтотОбъект`. |
| Имя элемента | Имя нового элемента формы. Запрещенные символы из имени удаляются автоматически. |
| Родитель | Имя элемента-родителя строкой или сам элемент формы. `Неопределено` — элемент добавляется на верхний уровень формы. |
| `СтруктураСвойств` | Дополнительные свойства элемента: ключ — имя свойства, значение — его значение. |
| `СтруктураСобытий` | Обработчики событий: ключ — имя события, значение — имя процедуры в модуле формы. |
| `ЭлементПеред` | Имя элемента или сам элемент, перед которым нужно вставить новый. |

Виды и варианты отображения задаются числами. Значение `0` везде означает «Авто» или значение по умолчанию.

| Параметр | Значения |
|---|---|
| Группировка группы | `1` — вертикальная, `2` — горизонтальная если возможно, `3` — горизонтальная всегда |
| Растягивание | `1` — да, `2` — нет |

## Реквизиты и команды
| Функция | Что делает |
|---|---|
| `СоздатьРеквизит()` | Создает один реквизит формы. |
| `СоздатьРеквизиты()` | Создает несколько реквизитов за один вызов. |
| `СоздатьРеквизитыТаблицы()` | Добавляет колонки в реквизит-таблицу. |
| `СоздатьКоманду()` | Создает команду формы и связывает ее с процедурой-действием. |

Тип реквизита задается готовыми функциями: `ОписаниеТипаСтрока()`, `ОписаниеТипаЧисло()`, `ОписаниеТипаБулево()`, `ОписаниеТипаДатаВремя()`, `ОписаниеТипаСправочник()`, `ОписаниеТипаДокумент()`, `ОписаниеТипаПеречисление()`, `ОписаниеТипаТаблицаЗначений()`, `ОписаниеТипаДинамическийСписок()`.

```bsl
// Один реквизит
ДФИ.СоздатьРеквизит(ЭтотОбъект, "Контрагент", ДФИ.ОписаниеТипаСправочник("Контрагенты"));

// Несколько реквизитов
Реквизиты = Новый Структура;
Реквизиты.Вставить("Сумма", ДФИ.ОписаниеТипаЧисло(15, 2));
Реквизиты.Вставить("ДатаОплаты", ДФИ.ОписаниеТипаДатаВремя("Дата"));
ДФИ.СоздатьРеквизиты(ЭтотОбъект, Реквизиты);

// Команда: имя, заголовок, имя процедуры в модуле формы
ДФИ.СоздатьКоманду(ЭтотОбъект, "Пересчитать", "Пересчитать суммы", "ПересчитатьСуммы");
```

Повторный вызов с тем же именем и типом реквизита ничего не меняет. Если реквизит уже существует с другим типом, библиотека вызывает исключение с описанием расхождения.

## Группы и страницы
| Функция | Что делает |
|---|---|
| `СздГруппаОбычнаяБезОтображения()` | Обычная группа без рамки и заголовка. Удобна как контейнер для компоновки. |
| `СздГруппаОбычная()` | Обычная группа с заголовком и слабым выделением. |
| `СздГруппаСтраниц()` | Контейнер для вкладок. Может принимать обработчик смены страницы. |
| `СздСтраница()` | Страница внутри группы страниц. |
| `СздГруппаКоманднаяПанель()` | Группа вида «Командная панель» для кнопок. |
| `СздГруппа()` | Универсальная группа, вид задается структурой свойств. |

```bsl
// Горизонтальная группа без оформления
ДФИ.СздГруппаОбычнаяБезОтображения(ЭтотОбъект, "ГруппаШапка", Неопределено, 3);

// Вкладки с обработчиком смены страницы
ДФИ.СздГруппаСтраниц(ЭтотОбъект, "Страницы", Неопределено, 1, 1, "СтраницыПриСменеСтраницы");
ДФИ.СздСтраница(ЭтотОбъект, "СтраницаОсновное", "Страницы", "Основное");
ДФИ.СздСтраница(ЭтотОбъект, "СтраницаДополнительно", "Страницы", "Дополнительно");
```

Обработчик смены страницы в модуле формы:

```bsl
&НаКлиенте
Процедура СтраницыПриСменеСтраницы(Элемент, ТекущаяСтраница)
КонецПроцедуры
```

## Поля
| Функция | Что делает |
|---|---|
| `СздПоле()` | Поле формы выбранного вида. |
| `СздПолеФлажок()` | Флажок, тумблер или выключатель. |
| `СздПолеНадписи()` | Поле надписи для вывода значения без редактирования. |
| `СздПолеГиперссылка()` | Поле надписи в режиме гиперссылки. |

| Параметр | Значения |
|---|---|
| Вид поля в `СздПоле()` | `1` — поле ввода, `2` — флажок, `3` — индикатор, `4` — переключатель, `5` — период, `6` — HTML-документ |
| Вид флажка в `СздПолеФлажок()` | `1` — флажок, `2` — тумблер, `3` — выключатель |

```bsl
// Поле ввода, связанное с реквизитом "Комментарий"
ДФИ.СздПоле(ЭтотОбъект, "ПолеКомментарий", "ГруппаШапка", "Комментарий", 1, "Комментарий");

// Флажок в виде тумблера
ДФИ.СздПолеФлажок(ЭтотОбъект, "ПолеСрочно", "ГруппаШапка", "Срочно", 2, "Срочно");

// Поле с обработчиком события
События = Новый Структура("ПриИзменении", "СуммаПриИзменении");
ДФИ.СздПоле(ЭтотОбъект, "ПолеСумма", "ГруппаШапка", "Сумма", 1, "Сумма", , События);

// Гиперссылка
ДФИ.СздПолеГиперссылка(ЭтотОбъект, "СсылкаПодробнее", "ГруппаШапка", "Подробнее");
```

## Декорации и кнопки
| Функция | Что делает |
|---|---|
| `СздДекорацияНадпись()` | Надпись с заданным текстом. |
| `СздДекорацияКартинка()` | Картинка из библиотеки картинок конфигурации. |
| `СздДекорация()` | Универсальная декорация со свойствами и событиями. |
| `СздКнопка()` | Кнопка, связанная с командой. Вид: `1` — обычная кнопка, `2` — гиперссылка. |

```bsl
ДФИ.СздДекорацияНадпись(ЭтотОбъект, "НадписьПодсказка", "ГруппаШапка", "Заполните все поля");
ДФИ.СздДекорацияКартинка(ЭтотОбъект, "КартинкаИнформация", "ГруппаШапка", "Информация");

// Кнопка для команды, созданной через СоздатьКоманду()
ДФИ.СздКнопка(ЭтотОбъект, "КнопкаПересчитать", "ГруппаШапка", "Пересчитать", "Пересчитать", 1);
```

## Таблицы и динамические списки
| Функция | Что делает |
|---|---|
| `СздТаблицаФормы()` | Таблица формы для реквизита-таблицы. Может сразу создать колонки и свою командную панель. |
| `СздКолонкаТаблицыФормы()` | Отдельная колонка таблицы. Вид: `0` — поле ввода, `1` — надпись, `2` — флажок, `3` — картинка. |
| `СздГруппаКолонокТаблицыФормы()` | Группа колонок таблицы. |
| `СздДинамическийСписок()` | Реквизит динамического списка и таблица формы для него. |
| `УстановитьПараметрыЗапросу()` | Устанавливает параметры запроса динамического списка. |
| `ПолучитьСтруктуруКолонокОбъекта()` | Возвращает структуру всех колонок объекта метаданных. |

Колонки описываются структурой: ключ — имя колонки, значение — заголовок.

Таблица значений на форме:

```bsl
// Реквизит-таблица и его колонки
ДФИ.СоздатьРеквизит(ЭтотОбъект, "Товары", ДФИ.ОписаниеТипаТаблицаЗначений());

КолонкиРеквизита = Новый Структура;
КолонкиРеквизита.Вставить("Номенклатура", ДФИ.ОписаниеТипаСтрока(100));
КолонкиРеквизита.Вставить("Количество", ДФИ.ОписаниеТипаЧисло(15, 2));
КолонкиРеквизита.Вставить("Отгружено", ДФИ.ОписаниеТипаБулево());
ДФИ.СоздатьРеквизитыТаблицы(ЭтотОбъект, "Товары", КолонкиРеквизита);

// Таблица формы с двумя колонками
Колонки = Новый Структура;
Колонки.Вставить("Номенклатура", "Номенклатура");
Колонки.Вставить("Количество", "Количество");
ДФИ.СздТаблицаФормы(ЭтотОбъект, "ТаблицаТовары", Неопределено, "Товары", Колонки);

// Еще одна колонка отдельно, в виде флажка
ДФИ.СздКолонкаТаблицыФормы(ЭтотОбъект, "ТоварыОтгружено", "ТаблицаТовары", 2, "Отгружено", "Товары.Отгружено");
```

Динамический список по основной таблице:

```bsl
Колонки = Новый Структура;
Колонки.Вставить("Код", "Код");
Колонки.Вставить("Наименование", "Наименование");

ДФИ.СздДинамическийСписок(ЭтотОбъект, "СписокНоменклатуры", Неопределено, , ,
	"Справочник.Номенклатура", Колонки);
```

Чтобы вывести все колонки объекта, не перечисляя их вручную:

```bsl
Колонки = ДФИ.ПолучитьСтруктуруКолонокОбъекта("Справочники", "Номенклатура");
```

Динамический список с произвольным запросом и параметром:

```bsl
ТекстЗапроса =
"ВЫБРАТЬ
|	Номенклатура.Ссылка КАК Ссылка,
|	Номенклатура.Наименование КАК Наименование
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура
|ГДЕ
|	Номенклатура.ЕдиницаИзмерения = &ЕдиницаИзмерения";

ПараметрыЗапроса = Новый Структура("ЕдиницаИзмерения", ЕдиницаИзмерения);

Колонки = Новый Структура;
Колонки.Вставить("Ссылка", "Номенклатура");
Колонки.Вставить("Наименование", "Наименование");

ДФИ.СздДинамическийСписок(ЭтотОбъект, "СписокПоЕдинице", Неопределено, ТекстЗапроса,
	ПараметрыЗапроса, "Справочник.Номенклатура", Колонки);
```

## Выпадающий список и переключатель
Эти функции сами создают реквизит формы с именем элемента, отдельно создавать его не нужно.

| Функция | Что делает |
|---|---|
| `СздВыпадающийСписок()` | Строковый реквизит и поле ввода с выпадающим списком значений. |
| `СздПереключатель()` | Числовой реквизит и поле переключателя. Вид: `1` — переключатель, `2` — тумблер. Значение реквизита — номер выбранного варианта. |

```bsl
Варианты = Новый Массив;
Варианты.Добавить("Наличные");
Варианты.Добавить("Безналичные");

ДФИ.СздВыпадающийСписок(ЭтотОбъект, "СпособОплаты", "ГруппаШапка", "Способ оплаты", Варианты);
ДФИ.СздПереключатель(ЭтотОбъект, "ВидОплаты", "ГруппаШапка", "Вид оплаты", Варианты, 2);
```

## Свойства и события
Любое свойство элемента можно задать обычной структурой. Для часто используемых свойств есть готовые функции, которые возвращают такую структуру:

| Функция | Какие свойства собирает |
|---|---|
| `СтруктураСвойствОсновные()` | Заголовок, вид, путь к данным, видимость, доступность, только просмотр, маска и другие. |
| `СтруктураСвойствПодсказка()` | Подсказка, ее отображение, подсказка ввода. |
| `СтруктураСвойствРасположение()` | Ширина, высота, растягивание, горизонтальное положение. |
| `СтруктураСвойствТаблицыФормы()` | Отображение таблицы, режимы ввода и выделения строк, шапка, подвал, высота в строках. |

Функции для уже созданных элементов:

| Функция | Что делает |
|---|---|
| `УстановитьСвойстваЭлементу()` | Применяет к элементу структуру свойств. |
| `УстановитьМножествоСтруктурСвойствЭлементу()` | Применяет к элементу до десяти структур свойств за один вызов. |
| `УстановитьСобытияЭлементу()` | Назначает элементу обработчики событий. |

```bsl
// Свойства при создании элемента
Свойства = Новый Структура("ТолькоПросмотр, Ширина", Истина, 30);
ДФИ.СздПоле(ЭтотОбъект, "ПолеИтог", "ГруппаШапка", "Итог", 1, "Сумма", Свойства);

// Свойства и события для уже созданного элемента
Поле = ДФИ.СздПоле(ЭтотОбъект, "ПолеКомментарий", "ГруппаШапка", "Комментарий", 1, "Комментарий");
ДФИ.УстановитьМножествоСтруктурСвойствЭлементу(Поле,
	ДФИ.СтруктураСвойствПодсказка("Произвольный текст"),
	ДФИ.СтруктураСвойствРасположение(40));
ДФИ.УстановитьСобытияЭлементу(Поле, Новый Структура("ПриИзменении", "КомментарийПриИзменении"));
```

## Удаление
Удалять можно только то, что было создано программно.

| Функция | Что делает |
|---|---|
| `УдлЭлемент()`, `УдлЭлементы()` | Удаляет один элемент формы или несколько по массиву имен. |
| `УдлРеквизит()`, `УдлРеквизиты()` | Удаляет один реквизит формы или несколько по массиву имен. |
| `УдлРеквизитИЭлемент()` | Удаляет реквизит и элемент с одинаковым именем. |

```bsl
ДФИ.УдлЭлемент(ЭтотОбъект, "ПолеКомментарий");
ДФИ.УдлРеквизит(ЭтотОбъект, "Комментарий");

// Выпадающий список и переключатель создают реквизит и элемент с одним именем
ДФИ.УдлРеквизитИЭлемент(ЭтотОбъект, "СпособОплаты");
```
